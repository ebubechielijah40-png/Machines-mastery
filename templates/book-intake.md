# Book Intake Template

Status: SOURCE NOT PRESENT until an actual original is inspected.

Record resource ID, title/author as printed, edition, format, lawful availability basis (no personal receipts), local path, SHA-256 and inspection date. Run the fingerprint tool only on the actual file. Inspect text, mathematical notation and diagrams; do not infer readability from extraction success alone.

Define the locator convention: printed page/section versus PDF index or EPUB section. Record unreadable or missing parts and stop affected work.

BOOK_MAP must list inspected chapters/sections, dependencies, foundational/supporting/advanced roles, MUST STUDY DEEPLY/REFERENCE/OPTIONAL DEPTH/HISTORICAL classifications, curriculum links, project relevance and experiment relevance. Explain the first selected unit before generating it.

CONCEPT_INDEX maps only inspected concepts to artifacts and claim IDs. SOURCE_INDEX records important claim locators and edition evidence. PREREQUISITES records required/recommended/concurrent concepts and learner evidence. Do not populate chapter names from web summaries.
