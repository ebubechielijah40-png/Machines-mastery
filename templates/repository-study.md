# Repository Study Template

Record original URL, owner versus verified creators, exact commit, LICENSE/NOTICE, acquisition date and local path. Unknown means UNVERIFIED — source required.

## Architecture inspection

Establish purpose, entry points, major components, control flow, data flow, important data structures, interfaces, dependencies, state, storage, networking, security boundaries and tests. Mark genuinely absent components as not applicable with evidence. Do not infer behavior from filenames.

## One operation end-to-end

Trace input → parsing → representation → computation → state change → storage → output where applicable. Cite commit, file, symbol and inspected locations at each transition. Separate documentation claims from source inspection and runtime observations.

## Reproduction and attribution

Record what was reproduced, independently implemented and modified. Preserve notices. List proposed versus actually executed commands, prerequisites, raw outputs, test outcomes, gaps and next inspection target.
