# Mastery Review Template

Record unit ID, date, assessor, previous state and proposed state. State assistance used, including AI output, references, hints and solution access.

## Learner attempt

Preserve original unaided answers or implementation before correction. Link dated evidence; do not replace it with an assistant's improved explanation.

## Criteria

Assess recall, mechanism explanation, assumptions, failure analysis, transfer, implementation/formal construction and experimental prediction/analysis. Give criterion-specific evidence and note inapplicability with reasons.

## Gaps and next review

List remaining core misconceptions and the next small action. Schedule delayed unaided recall and a new transfer problem before MASTERED. Record regression honestly. No automatic state change from generated files or tool tests.
