# Original instructional course routes

The2026-10-22 baseline found twelve substantially repeated navigation templates.
This continuation replaces their bodies with subject-specific original entry
chapters, developed lessons, actual builds and explicit limits. **None of these
broad coursebook scopes is complete.** They are PARTIAL routes into stronger
bounded units; titles are not evidence that every important concept has been taught.
The historical [baseline audit](../research/quality/2026-10-22/book-coursebook-audit.json)
is retained as a record of the earlier state.

| Route | Developed entry and linked mechanisms | Material still requiring depth |
| --- | --- | --- |
| [Machine foundations](01-machine-foundations.md) | Finite state, executable byte CPU, physical-model boundaries | Device physics, complete digital construction and hardware validation |
| [Systems programming](02-systems-programming.md) | C objects/compile/link, arena, OS models, shell | Full ABI/runtime, drivers, filesystems and kernel construction |
| [Algorithms](03-algorithms.md) | Arrays and20 distinct graph contracts, proofs/oracles | Other data structures, broad DP and further analysis |
| [Networks/distributed](04-networks-distributed.md) | Streams, strict HTTP subset, stamped state reconciliation | Routing/congestion, transport implementation, consensus and durable operation |
| [Data systems](05-data-systems.md) | WAL, relational/NULL semantics, SQLite isolation | B+trees, optimizer, compaction, broad concurrency/storage engines |
| [Security/cryptography](06-security-cryptography.md) | HMAC lineage, authority/truth, ideal DP proof and limits | Ciphers/protocols/key management, PQ mechanisms and production security |
| [ML/AI](07-ai-ml.md) | Gradients/AD, attention, trained tiny decoder, tokenizer, retrieval/controller | Broad model families, distributed training, alignment and learned agents |
| [Robotics/control](08-embedded-robotics.md) | Force/energy, motor states, sampled PID/sensors | Kinematics/estimation/planning and validated hardware integration |
| [Biology](09-computational-biology.md) | Molecular bridge, alignment, drift/selection/phylogeny | Broad omics, structural/system biology and public-data validation |
| [Quantum](10-quantum-machines.md) | Complex/statevector/density/noise/repetition recovery | General algorithms/QEC/compilation and hardware interfaces |
| [Research](11-research.md) | Primary-paper evidence, clocks/FFT/task-publication practicum | Most domain/paper quotas and historical benchmark reproductions |
| [Production](12-production.md) | Ledger/cluster/serving experiments and outcome contracts | Complete SLO/deployment/recovery/scalability instruction and operation |

Each unit's exact source inspection and code/experiment evidence is local to that
unit. A linked source is not a reconstructed chapter. Commercial book originals
are still absent; their per-book maps/claims remain independently audited under
[books](../books/README.md). No copied commercial text is added, and learner mastery
is never inferred from authored lessons or passing repository tests.
