# Hints

1. A delete can be invisible when replay begins from empty state.
2. Global version adds a base and a suffix; local frame numbering restarts.
3. A pointer can be well formed while a named dependency is absent.
4. Separate what another process sees from what survives losing the kernel.
5. Include the interval between selecting a filename and using it.
6. A lock belongs to an opened object, not a magic string.
7. The second arithmetic decision was made before the first write committed.
8. Absence also changes when a key is inserted, deleted or reinserted.
9. Reconciliation needs semantic operation identity or state, not just exception type.
10. The checksum belongs to the entire batch; no partial operations are applied.
11. The older snapshot may predate an acknowledged operation.
12. Compaction preserves final state, not all historical explanations.
13. Multiply left/right multiplicities; include output costs in each model.
14. A prediction is not a memory grant enforcement mechanism.
15. The hot key contributes90×90 pairs before considering other keys.
16. Use two identical-key left rows and one right row.
17. Only offset4 is new after restart.
18. Imagine a crash immediately after the first of two separate commits.
19. The implementation skips any offset≤the retained offset.
20. SQLite cannot atomically commit another service's inbox.
21. Hide the references until an independent observable contract passes.
22. A predicate can involve rows or absences that were never individually updated.
