# Post-quantum transition

Fault-tolerant quantum algorithms threaten factoring/discrete-log public-key systems, while symmetric search sees a different quadratic speedup model. Post-quantum cryptography changes key/ciphertext/signature sizes and protocol constraints. Migration is inventory work: find where vulnerable algorithms exist, how long confidentiality must survive, and whether data can be harvested now and decrypted later. Do not confuse quantum key distribution with a general replacement for cryptography.
