# Protocols and PKI

TLS-like security combines key exchange, authentication, transcript binding, key derivation, and authenticated encryption. Certificates bind names to keys through a trust system. Validation includes chain, validity, hostname, algorithm policy, and revocation/operational assumptions. Exercise: diagram a browser-to-server handshake and label which message prevents which attack. Then capture a local HTTPS handshake with safe tooling and map observed fields to the model.
