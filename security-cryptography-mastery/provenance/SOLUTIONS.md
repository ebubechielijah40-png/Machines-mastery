# Checkable solutions: authenticated provenance

1. Seq1 and seq2 produce counts 1 and 2 with last[sensor] 1 and 2. Each changes the tip and last room value. Replay1 raises SequenceError and leaves state at two. Correctly tagged seq3/outside raises AuthorizationError before any append and also leaves it at two; seq3/room can still be accepted next. A rejected request does not consume a sequence.
2. Inner bytes for `00 ff 0b` are `36 c9 3d`; outer bytes are `5c a3 57`. A long key is first replaced by its 32-byte SHA-256 digest, then padded to 64. The RFC 4231 vector in the lesson tests the nesting against an independent source; comparison with stdlib over key lengths 0,1,32,64,65,150 checks both sides of the block-length branch. Neither proves security.
3. Changing unit from milli_celsius to celsius rejects schema even before the tag mismatch. Changing a legal stream or producer changes canonical authenticated bytes and invalidates an unchanged tag. Silently ignoring unknown semantics-bearing fields lets a downstream consumer attach meaning the authenticator never approved. An explicit versioned schema must decide which fields have meaning.
4. JSON `true` becomes Python True and compares equal to one. The lab rejects it for `v`, `seq` and the measurement using exact-type checks. String `"1"` also rejects rather than coercing. Configuration booleans likewise should not silently mean numeric limits.
5. Whole-line removal leaves a valid one-entry prefix; without an expected tip it reopens. With the former final tip it raises IntegrityError. Cutting a line leaves an incomplete trailing record and always raises IntegrityError. Trusted-tip freshness and availability remain external requirements.
6. A completed append can be visible despite fsync reporting failure; subsequent power loss is a different question. The object is poisoned instead of guessing. Reopening may recover last sequence1, so retry1 is a replay. An idempotent result lookup could bind identity+sequence+content digest and return the original result for an exact retry; different content under the same ID must reject. Atomicity of that lookup and append is additional work.
7. The trusted local caller supplies `snapshot(principal)`. That is a model boundary, not credential verification. In a service, verified transport/session credentials should map to a server-side principal; a JSON `principal:'analyst'` field is only an untrusted claim until independently verified.
8. A useful reconstruction must pass fresh tests for duplicate keys, reordering, bool numerics, bounds, exact rational output, replay and unknown outcomes. A test that generates both expected and actual tags with the same helper cannot independently validate the cryptographic construction.
9. A valid image digest/signature does not establish that the specimen came from the claimed patient, that the instrument was calibrated, or that the biological conclusion follows from the image. Chain-of-custody evidence, independent controls and scientific analysis address different uncertainties.
