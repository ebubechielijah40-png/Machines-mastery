# Project ladder

P1 integrity checker; P2 authenticated local message channel using standard libraries; P3 password-authenticated API with secure password hashing; P4 role-based service with audit log; P5 signed/provenance data pipeline; P6 certificate/TLS inspection lab; P7 controlled vulnerable app and remediation; P8 post-quantum migration inventory. Every project requires threat model, tests, failure cases, observability, and a section titled “what this does not protect.”
