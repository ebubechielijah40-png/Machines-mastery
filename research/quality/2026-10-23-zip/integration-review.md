## Concrete findings and repairs

- The independent materials reviewer found that extreme positive parameters could
  underflow the ideal-chain modulus to0 despite the positive-output premise.
  Root added the existing positive/finite validation at the returned modulus and
  a permanent boundary regression. The new experiment replay fingerprints the
  repaired code; the earlier unit-local observation remains historical.
- A first carrier-neutrality test demanded tiny relative precision after
  cancellation of large nearly equal carrier values. The assertion now uses an
  eight-ULP scale bound; the independent high-precision quadratic and physical
  density/conductivity checks remain. The change documents floating-point
  resolution rather than altering semiconductor equations to fit an outcome.
- The reader checked B+ local byte codecs, split promotion, iterative graph
  validation, leaf-link ordering, row/page/image limits and staged page-budget
  failure. The accepted valid-checksum mixed snapshot is retained as a transaction
  counterexample. WAL rebuild reads the complete authority and never invents a
  checkpoint skip rule or durable publication protocol.
- ML review traced parameter sharing, full recurrent reverse accumulation,
  train-only preprocessing, every-parameter central-difference tests, exact
  count/correlation oracles and EM floors. The recurrent worked trace was
  recalculated with the implementation and rounded values corrected. Its forward
  memory result is separated from initialized backward sensitivity. Circular
  shift tests are structural checks, not natural-image generalization estimates.
- Explicit hash/heap/tree review checked equality after collisions, stability
  without payload comparison, two-child splice paths and size repairs. The tree
  is explicitly unbalanced; iteration avoids recursion but does not improve
  quadratic sorted insertion. Custom hash callbacks must be pure/stable; there
  is no arbitrary-callback transaction guarantee.
- DP review examined differing optimization/counting objectives,0/1 update
  order, exact-hop layers, interval pairing and minimax coverage. Source lecture
  typography was not copied as algorithm truth: minimum edit cost and exact-hop
  bases were derived independently and compared to finite search oracles.
- Operations review checked one transaction covering effect/identity/original
  response, retained-key reconciliation, semaphore admission, eligible-event
  accounting, queue/deadline boundaries and nearest-rank metrics. Actual process
  kills are described as application crashes; no physical power loss was tested.
  Slower offered load improves the saved case by trading away offered throughput.
- Binary review checked explicit mixed-endian serialization, modulo signed
  encoding, length-before-access, semantic checks despite recomputed CRCs and a
  separate binascii oracle. The known local target and supplied source make it a
  bounded discovery exercise, not a claim to reverse engineer unknown firmware.
- Rust/Zig/Go/Java review preserves language-specific boundaries: moved buffer
  versus clone; error cleanup versus arbitrary copied ownership; channel aliasing,
  cancellation and join; final reference versus deep immutability; volatile
  visibility versus compound atomicity. Ordinary/race/compiler/bytecode runs are
  actual, not extrapolations to all scheduler/compiler behavior.
- FIFO review derived old-state acceptance, full replacement and empty non-bypass
  before checking both HDLs against the same independent deque vectors. Each
  language rejects two intended semantic mutants. This is finite simulation,
  not all-state formal verification, CDC safety or synthesis/timing closure.
- Removed historical private `/tmp/machines-tools` fallbacks from the retained
  RISC-V/register runners. Trusted tools must now be resolved through PATH;
  external private compiler extraction paths are absent from runnable code.
