# Research and Session Records

Use [the research log template](../templates/research-log.md) for a bounded question, search strategy, inspected primary sources, inclusion/exclusion reasons, conflicting evidence, decisions and next test. Record failed retrievals rather than silently substituting sources.

Keep dated session logs here when meaningful work occurs. State who did the work (learner or assistant), what was actually inspected/executed and what remains uncertain. Store infrastructure validation outputs here, separate from curriculum experiment observations.

`setup-before.json` preserves the initial file sizes/hashes and directory names. `directory-migration.json` records the normalization of empty subject directories. Neither contains book text, credentials or private datasets.

No research result has been reproduced yet. A future research reproduction must name an original paper, identify domain prerequisites, pin data/code and specify agreement criteria before execution.
