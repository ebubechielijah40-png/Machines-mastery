# Scalability

Twelve-stage progression of this same contract: V1 single-process in-memory prototype (planned comparison); V2 persistent database (implemented); V3 concurrent callers (lock-conflict test only, not a concurrent server); V4 bounded connection pool (planned); V5 bounded cache (implemented under single-writer assumption); V6 background workers (planned); V7 durable queue/idempotent jobs (planned); V8 multiple instances (stale-cache failure demonstrated, coherent design pending); V9 load balancing (planned); V10 database bottleneck/index comparison (implemented); V11 replication/partitioning (planned); V12 recovery (rollback/retry/reopen checks implemented; backup/restore and crash recovery pending). At each stage save baseline, bottleneck hypothesis, change, new measurement and correctness/failure comparison. Unimplemented stages are not released lessons.
