# Logic to CPU

Project J-01 / P01. Status: PREPARED. Stage A: NOT STARTED. No implementation exists.

Build understanding along logic → gates → combinational circuits → arithmetic → state → memory → CPU. The end target is a small, explicitly specified machine whose instruction-by-instruction state can be predicted and tested.

Read [ORIGIN_AND_ATTRIBUTION.md](ORIGIN_AND_ATTRIBUTION.md), [PREREQUISITES.md](PREREQUISITES.md) and [DESIGN.md](DESIGN.md) first. Begin with a paper-level gate contract after the relevant source unit is studied. Select a simulator or implementation language only when the learner's prerequisites support it.

Stage A will reproduce an identified educational mechanism. Stage B will implement that mechanism independently. Stage C will inject faults and compare predictions with observations. Stage D remains unplanned until evidence shows understanding. No generated scaffold is claimed as the learner's implementation.
