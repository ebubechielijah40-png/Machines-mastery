# Assisted project learning standard

Every major project should be learnable without an external tutorial and should resist passive copying.

## Required files

- `README.md` — problem, outcome, learner path
- `PREREQUISITES.md` — exact internal links
- `DESIGN.md` — architecture after A1 attempt
- `CHECKPOINTS.md` — small milestones and acceptance tests
- `HINTS.md` — progressive hints
- `TESTS.md` — correctness/failure/performance test plan
- `EXPERIMENTS.md` — hypotheses and measurements
- `PRODUCTION.md` — what a real deployment adds
- `LIMITS.md` — what the toy project does not model
- `REFERENCE_IMPLEMENTATION/` — only when licensing/safety permits, hidden until attempt

## Assistance ladder

A0: acceptance criteria only.
A1: questions that force design choices.
A2: interfaces/data structures/checkpoints.
A3: detailed implementation guidance.
A4: reference solution and comparison exercise.

After A3/A4, reconstruct a smaller version from memory. That prevents “guided completion” from being mistaken for independent capability.
