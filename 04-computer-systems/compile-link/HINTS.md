# Hints

1–2. A declaration may be usable before any address/definition exists in this object.
3–4. Count byte reads and distinguish the output's write from a zero-trip loop.
5. A compiler can emit an unresolved reference into an object.
6–7. The same arithmetic need not use the same temporary locations.
8. Initialize output to a recognizable sentinel, then submit a supported invalid case.
9. Think about representation, locations, alignment and preservation, not just names.
10–12. Keep intermediate objects; do not inspect only the final console output.
