# Dynamic programming: released bounded problem set

[The twenty actual contracts](PROBLEMS.md) replace the previous generic seeds.
Each has a prompt, hint, proof/cost/counterexample, shared runnable reference and
local test. [The shared independent tests](code/test_dp.py) enumerate alternative
small solutions. Run `python3 algorithmic-problem-solving/topics/dynamic-programming/run_all_tests.py`
from the repository root. Broad algorithm-domain completion is not claimed.
