# Mechanism patterns

Read [the derived lesson](LESSON.md) before solutions.

- FIFO layer invariant: shortest hops and nearest source.
- DFS active/finished states: cycle witness and strong components.
- Remaining-indegree invariant: dependency order and DAG recurrence.
- Relaxation with different finalization assumptions: nonnegative, binary, arbitrary or acyclic weights.
- Escape-to-ancestor invariant: bridge and articulation certificates.
- Cut exchange: minimum installed forest.
- Residual reachability: flow upper/lower certificate.
- Alternating reassignment: maximum cardinality matching.

Each objective has a different proof obligation. A pattern name does not justify using it after its assumptions fail.
