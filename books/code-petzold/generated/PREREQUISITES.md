# Prerequisites — Code

## First selected unit

[EXPLANATION] These are curriculum entry checks, not an author-provided prerequisite list. No learner ability has been assessed.

Required: distinguish two marks, count short intervals, read a small lookup table and distinguish prediction from observation. Check these with a table containing `E → .` and `T → -`: encode TE; decode dot and dash **with a character separator between them**; explain why “on” differs from “on for three agreed time units.” A difficulty is a useful diagnostic, not a reason to skip the mechanism.

No programming, binary arithmetic, electronics, prior Morse knowledge or cryptography is needed. Python is optional; paper tracing supports the first experiment.

## Conceptual order

```text
shared alphabet/codebook → physical signal and time unit
→ boundaries → unfinished decoder state → recovery limits
```

Study timing and decoding together. Discuss efficiency only after specifying the representation, boundaries and cost measure. This first unit is within U01, not the whole U01 curriculum scope. Neither U00 nor U01 becomes learned because these files exist.
