# Start here: messages need an agreement

Preparation: READY. Learner state: **NOT STARTED**. This is the first bounded learning unit within U01, not all of U01. No second unit has been prepared.

Your goal is to explain how a receiver turns a changing signal into a message, and to show exactly which missing agreement makes recovery impossible. You do not need to memorize Morse code, program, or know electronics.

## First attempt — before reading the explanation

Use this tiny table: E is `.`, T is `-`, A is `.-`, N is `-.`.

1. Write a representation of TE with a visible character separator.
2. Someone sends `.-` without any boundaries. Is the message necessarily A? Give another possible message.
3. A lamp is on for 300 milliseconds. Can you identify the letter without any other agreement? Write what you would need to know.
