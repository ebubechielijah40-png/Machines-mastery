# Hints — after an attempt

1. Separate text → marks from marks → timed physical changes.
2. Look for a longer codeword beginning with `.`.
3. First write `-. / .`; replace each boundary using its role, then multiply every duration by two.
4. Compare one two-mark letter with two one-mark letters.
5. Divide each duration by the receiver's τ rather than reasoning from milliseconds alone.
6. Ask whether the changed frame still obeys every grammar rule.
7. Separate event-list EOF from a physical observation of darkness.
8. Use two different inputs that map to exactly the same transmitted result.
9. A mark count ignores the duration of the marks and gaps.
10. Fixed length helps grouping only when alignment is known and preserved.
11. A program receives numbers, not photons.
12. Measure variability and error under defined conditions; this unit has no physical measurements.
