# Assessment protocol — no outcomes recorded

State: **NOT STARTED**. Use the central [mastery review template](../../../../../templates/mastery-review.md). Save date, original answers, assistance, mistakes and corrections. Prepared answers and passing reference tests are not learner evidence.

| Capability | Unaided task | Required evidence |
| --- | --- | --- |
| Recall/explanation | Explain text, marks, physical signal and interpretation without confusing them | Your explanation naming agreements and failure assumptions |
| Application | Encode and decode a fresh permitted message selected after study | Full trace with boundary and EOF handling |
| Formal construction | Prove the A/ET collision prevents universal recovery without boundaries | Two distinct inputs, same representation, contradiction for an inverse |
| Implementation | Design a paper decoder or independent program before viewing reference code | State definition, transition rules, valid and invalid examples |
| Experiment | Predict E-002, execute, compare with prediction | Dated prediction and actual raw trace, not expected output copied into results |
| Failure analysis | Explain how a gap change yields valid but wrong text | Exact changed event, resulting text and limits of syntax checks |
| Transfer | Design a fixed-length two-mark code and diagnose a lost mark | Alignment assumptions and a concrete failure trace |
| Delayed recall | Repeat mechanism and fresh transfer next session and after a delay | New unaided attempt, errors and reviewer feedback |

Do not automatically advance even to MAPPED because a map exists. For MASTERED, apply all central evidence requirements with no unresolved core gaps; scope any eventual assessment to this bounded unit. A paper construction may satisfy the implementation criterion here with explicit reviewer rationale; it does not certify programming skill.

After an attempt, schedule the next review using the repository's proposed cadence. No dates or assessor outcomes are fabricated in advance. Stop before the second learning unit.
