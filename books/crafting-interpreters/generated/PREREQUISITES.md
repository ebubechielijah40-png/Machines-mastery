# Prerequisites and exit tasks

Study [Python entry](../../../02-programming/python-entry/README.md),
[aliases](../../../programming-languages-mastery/08-python/units/objects-and-aliases/README.md)
and the [expression-language build](../../../projects-guided/p10-language/README.md)
first. Be able to distinguish a variable name, a mutable object, an AST node and
an executing function call. No prior understanding is presumed merely because
these files exist; learner evidence remains NOT STARTED.

Before beginning, trace a dictionary updated through two aliases, construct an
expression tree for2+3, and explain why parsing that tree does not evaluate it.
The chapter explains frames, closures, lexical distance and static analysis from
those prerequisites. Finish by reconstructing the late-declaration failure and
its resolver repair without copying the reference.
