# Capability map

At the end of the **learning work** in this repository, the target is not “I have read many topics.” The target is a repeatable method for unfamiliar systems.

## System investigation capability

Given an unfamiliar system, you should be able to identify boundaries, inputs, outputs, state, interfaces, data flow, control flow, energy flow where relevant, timing, constraints, trust boundaries, and failure modes; then form hypotheses, instrument the system, run discriminating experiments, revise your model, reproduce important behavior, and build a simplified reimplementation.

## Software capability

You should be able to move down and up abstraction layers: source → compiler/runtime → OS → ISA → microarchitecture → digital logic, and application → protocol → network → service → database → storage. You should understand why production behavior differs from a toy program: load, concurrency, latency, partial failure, observability, deployment, compatibility, and security.

## Research capability

You should be able to distinguish observation, data, evidence, model, inference, claim, and conclusion; reconstruct a paper's problem/method/evidence chain; reproduce bounded results when materials permit; and state what the evidence does **not** establish.

## Limits

No finite curriculum makes a person omniscient. Specialized hardware, advanced biology, frontier cryptography, quantum error correction, chip fabrication, and other fields require years of focused work, specialized equipment, and primary literature. The transfer skill is knowing how to discover what you do not yet know.

## Quantum-machine capability
You should be able to explain ideal qubit state, phase/interference, entanglement, measurement, basic circuit simulation, why statevector simulation scales exponentially, how algorithms claim speedup, why noise/error correction dominate hardware engineering, and how quantum threats differ across cryptographic primitives. This is foundational capability, not quantum-hardware fabrication expertise.
