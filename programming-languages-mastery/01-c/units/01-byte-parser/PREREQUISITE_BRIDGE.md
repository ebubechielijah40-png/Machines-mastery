# Bridge before the parser

Required internal lessons: [counting/units](../../../../foundations/mathematics/counting-and-units/README.md), [finite representations](../../../../foundations/mathematics/finite-representations/README.md), and [C interface reading](../../../../foundations/programming/c-reading/README.md). Return here after their practice; none is currently learner-mastered.

Mathematics: base-256 positional value, bounds and inequalities. Programming: declarations, arrays, pointers, conditions, returns and compilation, taught in the C bridge. Systems: Code's representation contract is useful, not a prerequisite CPU course. Physics/electronics/chemistry/statistics: not required for this abstract parser; no physical, population or timing inference is made. Compilers and ABI are introduced only at the bounded observational level in the lesson.
