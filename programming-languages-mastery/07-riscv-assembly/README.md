# RISC-V assembly

Infrastructure and introductory model; learner NOT STARTED. Required curriculum gate: U03; take exact lesson bridges before an exemplar. Prepared exemplar: [ADDI encoding and state](units/01-addi/README.md).

Purpose: an explicit ISA bridge between programs and HDL.

```text
C → assembly → instruction bits → register transitions → HDL datapath
```

Projects, in increasing scope: small ISA traces; assembler inspection; calling convention; C linking; processor-model comparison. These are plans, not implementations.

[Primary evidence](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html); full semantics and version-specific details outside prepared units remain UNVERIFIED — verification required.
