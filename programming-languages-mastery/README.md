# Language mastery as systems investigation

Early use Shell/Bash, Python and C; then x86-64 and basic RISC-V; bring C++, Rust and Zig into systems components; SQL into data systems; Go into networking; Java into runtime study; ARM64 into embedded work; SystemVerilog/VHDL into digital hardware. This is dependency-driven, not fourteen sequential courses.

- [C](01-c/README.md): portable machine-oriented programming and explicit object lifetimes.
- [C++](02-cpp/README.md): abstractions whose resource costs can be investigated.
- [Rust](03-rust/README.md): resource and memory constraints expressed through ownership.
- [Zig](04-zig/README.md): explicit allocation, control and interoperability.
- [x86-64 assembly](05-x86-64-assembly/README.md): instruction-level register and memory effects.
- [ARM64 assembly](06-arm64-assembly/README.md): a second instruction-set view for embedded and mobile systems.
- [RISC-V assembly](07-riscv-assembly/README.md): an explicit ISA bridge between programs and HDL.
- [Python](08-python/README.md): names, objects and runtime-supported automation.
- [Go](09-go/README.md): networked services and explicit concurrent structure.
- [Java](10-java/README.md): a specified virtual-machine boundary.
- [SQL](11-sql/README.md): declarative relational computation.
- [Shell/Bash](12-shell-bash/README.md): process composition and operating-system interfaces.
- [SystemVerilog/Verilog](13-systemverilog/README.md): hardware structure and state-transition descriptions.
- [VHDL](14-vhdl/README.md): strongly specified hardware interfaces and event models.

[Toolchain map](TOOLCHAINS.md) connects the boundaries. Every topic requires source versioning and internal prerequisites; all learner states remain NOT STARTED.
