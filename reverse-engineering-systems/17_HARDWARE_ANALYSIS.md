# Hardware Analysis

[EXPLANATION] Original investigation method, not a claim about uninspected devices.

Begin unpowered with labels, interfaces and verified device data. Logical simulation and actual voltage/timing are different evidence. Unknown supply or stored energy blocks energizing.

Practice: List measurements needed before connecting an unfamiliar board; do not infer a pinout from appearance.

Record the boundary, inputs, current state, predicted output, observation method, assumptions and a result that would force revision. When no distinguishing experiment is available, report the equivalence class of surviving models. No observation or mastery is claimed by this method page.
