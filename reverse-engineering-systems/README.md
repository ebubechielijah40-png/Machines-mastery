# Reverse-engineering systems

Permanent core track, integrated with U00/U12 and domain-specific gates. Original workflow chapters below are prepared methodology; they are not complete tutorials in every analysis tool.

```text
system → boundary → inputs/outputs → components → interfaces → state
→ control → data flow → energy flow → timing → constraints → failures
→ hypotheses → experiments → model → reproduction → validation
```
