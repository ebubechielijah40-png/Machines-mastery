# Universal Workflow

[EXPLANATION] Original investigation method, not a claim about uninspected devices.

Choose the boundary and a repeatable initial state. Enumerate inputs/outputs, propose components/interfaces, trace state/control/data/energy/timing, then test assumptions and failure modes. Revise the model before reproducing; validate the replica on withheld cases.

Practice: Build a table with hypothesis, prediction, distinguishing intervention, observation, decision and unresolved alternative.

Record the boundary, inputs, current state, predicted output, observation method, assumptions and a result that would force revision. When no distinguishing experiment is available, report the equivalence class of surviving models. No observation or mastery is claimed by this method page.
