# Documentation completeness contract

A track is “prepared” only if a learner can find:

- a start page and prerequisite route;
- deep explanation with definitions and mechanisms;
- concrete worked examples;
- exercises with separated hints/solutions where solutions exist;
- executable/simulatable examples where feasible;
- experiments with expected vs observed results separated;
- projects with graduated assistance;
- production/real-world/scalability discussion where relevant;
- security/privacy considerations where relevant;
- explicit limits and things the model cannot establish;
- reconstruction/transfer tasks.

This contract applies across computing, machines, biology, quantum computing, mathematics/physics foundations, and research practice.
