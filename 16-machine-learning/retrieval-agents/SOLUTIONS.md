# Checkable solutions

1. Score=1/sqrt2. Scaling q by a>0 multiplies its numerator and norm by a, which
   cancel. A negative scale reverses direction and does not preserve cosine.
2. Common term idf=log(4/4)+1=1; rare term idf=log(4/2)+1≈1.693147.
3. Query vector is0, so cosine is undefined. Return no evidence and let a later
   policy abstain rather than inventing relevance.
4. `commit` versus `committed`; `car` versus `automobile`. Case folding alone
   solves neither. A stemming change can also merge distinctions incorrectly.
5. Add2+3→5; multiply5*4→20; divide20/2→10. Calls, attributes and powers are
   rejected even if their printed spelling resembles a calculation.
6. A labeled target at rank2 yields recall@1=0, recall@2=1. Returning only the
   first paragraph can still answer incorrectly. Show actual corpus/query scores.
7. Require an exact argument-key set, validate type excluding bool where integer
   meaning matters, bound resource use, and test failures. No general reference
   answer can certify the security of an arbitrary new capability.
8. The search observation exists, but controller has not chosen a final result;
   returning success would confuse stage completion with task completion.
9. A source can be stale/false/irrelevant. Citation existence is mechanically
   checkable; entailment and correspondence to reality require separate evidence.
10. Labels a and b get different arrays, but an unauthenticated caller can choose
    a. An authenticated service must derive session identity from trusted context,
    enforce access/retention and bound aggregate storage; no such system is here.
11. Expected outcomes should be frozen per trace: rejected unknown tool, terminated
    repeated actions at budget, unsupported answer rejected by an added support
    checker. The reference extracts text and does not implement semantic entailment.
12. Report original and changed retrieval on identical labeled queries with
    preprocessing/version control. Confidence is limited by query count/selection;
    more favorable queries selected after inspection are a biased test set.
13. Assess vectors/zero cases20%, typed grammar/capabilities20%, loop states20%,
    independent evidence/evaluation20%, limits/reconstruction20%. Executing an
    unlisted tool or claiming universal injection resistance fails the contract.
