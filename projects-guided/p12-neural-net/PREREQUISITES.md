# Entry checks and bridges

Use [functions/algebra](../../foundations/mathematics/core/01_ALGEBRA_FUNCTIONS.md),
[vectors/maps](../../foundations/mathematics/core/03_VECTORS_MAPS.md),
[derivatives/optimization](../../foundations/mathematics/core/04_CALCULUS_OPTIMIZATION.md)
and [numerical error checking](../../foundations/mathematics/change-error-and-evidence/README.md).
Python functions, mutable objects, loops and lists are required; no tensor
framework is a prerequisite. Read source code only after an original attempt.

Before A0, compute `(3*3+1)^2`; expand `(x+h)^2-x^2` and divide by h; explain
why `(a+b)^2` contains a cross term. Before A2, order a graph so every input is
available before its consumer. Before A4, calculate the mean of four losses and
explain why the negative derivative suggests a local decrease. Before reporting
evaluation, distinguish an observation optimized against from one withheld.

A wrong answer identifies a concrete bridge to revisit. The model's word
"neural" does not require biological neuron dynamics, physical measurement or
an assumption that symbolic variables have units. These synthetic inputs,
parameters and losses are dimensionless.
