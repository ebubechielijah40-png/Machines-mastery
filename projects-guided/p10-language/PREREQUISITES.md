# Prerequisites with concrete checks

Use [proofs and structural recursion](../../foundations/mathematics/core/02_PROOFS_DISCRETE.md)
and [Python objects/aliasing](../../programming-languages-mastery/08-python/units/objects-and-aliases/README.md).
Before this project, write a list loop that consumes tokens without skipping one,
walk a nested tuple recursively, and explain why a copied dictionary of immutable
numbers can isolate rebinding. Derive1/3+1/6=1/2 using a common denominator.

If these checks fail, complete the corresponding prerequisite before writing the
parser. This project then feeds compiler ASTs, interpreters, configuration DSLs
and query-language parsing; it does not require an unintroduced compiler backend,
assembly ABI, automata theory or operating-system implementation.
