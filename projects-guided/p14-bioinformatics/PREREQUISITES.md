# Concrete prerequisite bridge

- **Mathematics:** integer addition/ordering, maximum, index pairs, a finite table, and induction. The [alignment lesson](../../18-computational-biology/02_SEQUENCE_ALGORITHMS.md) defines prefixes, zero-based indices, half-open slices, and the final-column proof before use. No calculus is needed.
- **Programming:** Python strings, lists, loops, conditions, functions, tuples, imports, exceptions, file bytes, JSON, and command-line arguments. The [starter](starter/inspect_fasta.py) is a runnable byte-read → parse → inventory example. If these constructs are unfamiliar, use the [Python route](../../programming-languages-mastery/08-python/README.md) and do not claim this project's programming gate is already met.
- **Biology/chemistry/materials:** understand that a sequence is a representation of molecular order, not the organism. The parser's ACGTN alphabet is a software contract; no chemistry calculation or wet-lab technique is required here. Read the [domain handbook](../../18-computational-biology/DEEP_HANDBOOK.md) for context; the brief molecular-foundations file is not a complete prerequisite course.
- **Statistics/probability:** no statistical claim is necessary to run exact alignment. The optional finite-null experiment defines its conditional sample space explicitly. A tail fraction is not a calibrated biological inference.
- **Physics/electronics:** not required for this computational string build; no physical measurement or electrical device is modeled.
- **Prior systems:** byte identity, input validation, and finite memory. [Production notes](PRODUCTION.md) introduce the project's resource and trust boundaries before public deployment is even considered.

Readiness check: explain why two input strings can have several equally optimum alignments and why recording only the score loses information. If you cannot, complete the lesson and worked table first. No agent-generated file changes learner state.
