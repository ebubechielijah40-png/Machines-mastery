# Entry tasks

Use [Python entry](../../02-programming/python-entry/README.md) to read functions,
lists, dictionaries and exceptions. Use [discrete reasoning](../../foundations/mathematics/core/02_PROOFS_DISCRETE.md)
to distinguish a set from a sequence, prove an invariant and interpret a partial
order. Derive [clock/merge rules](../../15-distributed-systems/ordering-reconciliation/README.md)
before implementing a service around them.

Without code, trace red then blue versus blue then red; compare stamps(2,A)
and(2,B); distinguish a send event from the latest write in a snapshot; explain
why an erased key can be resurrected. A source-level process dictionary does
not provide authentication, durable storage or a reliable network channel.
No cryptographic primitive, physics or machine-learning knowledge is required
for this bounded build. Those are distinct later extensions.
