# Entry tasks

Write a list loop and a function with a clear return value from the
[Python entry unit](../../02-programming/python-entry/README.md). Explain aliasing
before promising that an operation does not mutate input. Use the
[proof unit](../../foundations/mathematics/core/02_PROOFS_DISCRETE.md) to state an
invariant and a termination measure separately. Distinguish V from E, a path
from a walk, and a directed edge from a symmetric undirected pair. No matrix
calculus, electronics or network deployment is assumed for these algorithms.
