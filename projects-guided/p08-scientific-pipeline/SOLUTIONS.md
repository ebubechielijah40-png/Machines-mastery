# Solutions: measurement analysis

1. Mean=1002 milli-Celsius; deviations -2,2,0; s²=8/2=4; variance of mean=4/3. Corrected result=1022 milli-Celsius=1.022 °C. Combined variance is `4/3+9=31/3` milli-Celsius squared; standard uncertainty is `sqrt(31/3)/1000` Celsius, about .003215 °C. These are standard-uncertainty calculations under the declared model, not a guaranteed coverage interval.
2. `Var(mean X)=[nσ²+n(n-1)c]/n² = σ²/n+(n-1)c/n`. For a nonnegative common covariance, the limit is c rather than zero. A shared offset produces covariance between every pair, explaining the uncertainty floor. Covariance choices must form a valid joint covariance matrix; arbitrary negative constants cannot remain valid as n grows without constraints.
3. Fixed integer milli-Celsius avoids binary-float and text-normalization ambiguity. A new decimal-Celsius version could parse a restricted decimal string into an exact scaled integer with declared precision and rounding rules. Accepting either unit based on a guessed numeric magnitude is not a safe conversion contract.
4. Expand `sum_ij(x_i-x_j)² = 2n sum_i x_i² - 2(sum_i x_i)²`. Dividing by `2n(n-1)` gives the centered sample variance. This oracle computes through a distinct identity and can expose a common denominator or centering error. Both methods can still share conceptual assumptions, so the hand example remains useful.
5. Compare recorded pvariance with 25+4/n and 29/n, allowing Monte Carlo sampling variation. A shared-calibration curve should approach 25, while the independent curve shrinks toward zero. Neither includes calibration drift, autocorrelation, instrument nonlinear response, uncertain trial distributions or sampling selection bias.
6. The attacker can replace the input, recompute SHA-256 and replace the manifest. An externally trusted expected digest or a MAC/signature with protected authority is needed for the corresponding integrity claim. A trusted digest still cannot establish physical truth of the originally hashed samples.
7. The tests must distinguish corrected mean from raw mean and individual-reading scatter from uncertainty of a mean. A single test where correction=0 and calibration uncertainty=0 cannot catch either confusion.
8. Add elapsed timestamps and repeated reference standards interleaved with samples, or compare a separately calibrated instrument while varying batch duration. A trend with elapsed time would challenge independence, but confounding environmental changes still need control. Three readings with only ordinal sequence contain no independent time/calibration evidence.
