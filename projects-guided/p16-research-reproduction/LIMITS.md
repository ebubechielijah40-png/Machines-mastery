# Explicit limits and remaining work

The project is complete as a bounded taught build with three mechanisms, independent tests, executed synthetic experiments and separated assessments. It is **not** a full reconstruction of every result in the source papers or a completed research curriculum.

| Boundary | Implemented evidence | Not established |
|---|---|---|
| logical clocks | finite valid schedules, graph closure, correct and broken receive rules, offline ordering | physical clocks, mutual-exclusion protocol, online delivery, failures, restart, consensus, authenticated logs |
| Fourier algorithm | positive-sign radix-two transform, direct oracle, small float experiments, convolution | original program, IBM7094 performance, mixed radices, arbitrary precision, a universal error bound, real sensor validation |
| task publication | deterministic integer counts, single winner per logical task, owned snapshots, retry order tests | actual master/worker runtime, network/storage recovery, GFS, atomic rename, durable state or exactly-once effects |
| privacy extension | original scalar density proof and worked analytical calculations | production randomness, numerical privacy proof, service side channels, application policy or a certified release system |

Primary source PDFs were inspected but are not bundled; open redistribution licenses were not established. Exact hashes and claim locators are recorded. Later research papers mentioned as follow-up are explicitly unverified in these units. A source quotation, an institution-hosted copy and independently reproduced behavior are different evidence types.

The paper-domain target of at least ten important verified originals per major domain is not met by these four new dossiers. Domains with only plans remain SCAFFOLDED. A meaningful next batch is a source-verified online-order protocol, a durable task-publication failure experiment, a higher-precision transform oracle and additional original papers across the remaining domains. Those are remaining implementation tasks, not completed features or hypothetical test results.
