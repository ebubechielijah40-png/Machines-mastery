# Solutions: privacy count release

1. q(D)=2. Neighbor counts are 1,2,3: remove a one, add/remove a zero, or add a one. All differences are at most one, and a neighboring difference of one exists, proving Δ=1. No claim about publishing n is needed.
2. Up to four added/removed one contributions change q by four, so b=4/.2=20 counts. Row-level b=1/.2=5 would provide only the row-level bound; a four-row change can have log ratio .8 rather than .2.
3. At b=3 the quartiles are `-3 ln2`,0,`3 ln2`. F(0)=.5 joins continuously. Uniform endpoints map to infinite tails in the ideal inverse; this finite implementation rejects endpoints. That rejection and finite uniform support are among the reasons it is not a certified implementation of the real-valued proof.
4. The log ratios are +.5,0,-.5 for b=2. For b=.5 they become +2,0,-2. On the left tail t<=10 the density ratio is exp(2), exceeding exp(.5); integrating over a nonempty interval in that tail gives an event-level violation.
5. One ε=1 release has b=1 and variance2. Each ε=.1 release has b=10 and variance200; averaging ten independent releases yields variance20 at the same conservative total budget1. Repetition is not a free accuracy improvement when the total is fixed. This comparison uses the scalar Laplace mechanism, not a universal optimality theorem for all private mechanisms.
6. A known seed makes the produced noise reproducible; subtracting it recovers the count. Reusing exactly the same noise across two counts makes their difference noiseless. The randomized distribution conditioned on attacker knowledge and the independent product assumption differ from the proof's conditions. A histogram over many unrelated synthetic seeds can still resemble Laplace and miss this disclosure.
7. Clipping a released value to a public fixed [0,100] adds no new dataset access. Clipping to a private n can reveal information about n through an altered output distribution and requires its own analysis. Calling an operation post-processing does not make new sensitive inputs free.
8. Tests can validate quartiles, exact budget arithmetic, sensitivity on finite enumerated samples, approximate moments and deliberate counterexamples. The continuous proof covers all real output events under its assumptions; it does not certify finite floating output support, accounting durability or process security.
9. A user can reset an in-memory object or route queries through a second one. Durable shared accounting bound to the protected population/query authority is required, with transactional reservation across requests and a recovery policy. Such a system is beyond this model and remains unfinished.
